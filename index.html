Privacy Policy

Effective Date: November 5, 2026
Publisher: ClickAway
Contact: hasanmahdi6060@gmail.com

ClickAway is an independent browser extension that helps users simplify repetitive workflows on supported Printify pages. This policy explains what information ClickAway processes, how it is used and stored, and the controls available to users.

1. Information We Process

ClickAway processes information that users enter, configure, or save in the extension, including product-profile names, sizes, prices, colors and variants, held variants, notes, linked product names or page paths, variation-name mappings, the selected profile, and floating-button positions and preferences.

When a user initiates an automation action on a supported Printify page, ClickAway reads relevant page information needed for the selected action, including product names, pricing values, variant labels and selection states, variation-name fields, and publishing-setting controls.

The current implementation does not intentionally access browser cookies, passwords, payment details, browsing history, or customer/order records. User-entered fields, especially notes and product names, may contain personal information if the user chooses to enter it.

2. How Information Is Used

ClickAway uses this information to save product profiles and preferences, apply configured prices, select colors and variants, set variation names, apply supported publishing settings, and enable backup and restore functionality.

Automation is initiated by the user. ClickAway does not independently trigger final product publishing or saving actions.

3. Local and Legacy Storage

ClickAway stores saved information in browser-local extension storage. Older versions may have stored profiles, the selected profile, and prices in browser sync storage; ClickAway may migrate those legacy values to local storage. ClickAway does not operate a separate backend server to store user profiles or settings. Browser synchronization behavior, where applicable, depends on the user's browser provider and settings.

4. Sharing and Transmission

The current ClickAway implementation does not independently send saved extension data to a ClickAway-operated server, analytics provider, advertising provider, or data broker. ClickAway does not sell user information.

When a user initiates automation, ClickAway interacts with the user's existing Printify browser session. Values entered into Printify may be processed by Printify under its own terms and privacy practices.

5. Backup and Restore

Users may export selected saved data to a JSON backup file on their device. A backup can include product profiles, the selected profile, and variation-name information. ClickAway reads a backup only when the user selects a file for import.

Downloaded backups remain under the user's control and are not automatically removed when extension data is deleted.

6. Data Retention and Deletion

Saved extension information generally remains in browser storage until changed or deleted by the user, subject to browser storage behavior. Users can manage individual profiles, export and restore backups, reset floating-button positions, and use Delete All Saved Data in ClickAway's Options page.

That deletion control removes ClickAway-owned local and relevant legacy sync data, verifies the targeted deletion, and reloads the extension. Deletion does not remove previously downloaded backup files or reverse actions already completed on Printify. Storage behavior after uninstalling or reinstalling may vary by browser.

7. Security

ClickAway uses browser extension APIs for user-requested functionality. Its debugger-based input functionality is restricted to supported Printify application pages and approved input commands. Users should keep their browsers updated and protect exported backup files. No software can guarantee absolute security.

8. Third-Party Platforms

ClickAway is an independent product and is not affiliated with, endorsed by, or sponsored by Printify, Etsy, Google, or Microsoft. Use of third-party platforms is subject to their respective terms and privacy policies.

9. Changes to This Policy

We may update this policy when ClickAway's features, data practices, or applicable requirements change. The effective date will be updated when a revised policy is published.
